# bo4e/homebrew-tap

Homebrew tap for [BO4E-CLI](https://github.com/bo4e/BO4E-CLI).

## Usage

```bash
brew install bo4e/tap/bo4e-cli
```

Equivalent to:

```bash
brew tap bo4e/tap
brew install bo4e-cli
```

Works on macOS (Intel + Apple Silicon) and x86_64 Linux via
[Homebrew on Linux](https://docs.brew.sh/Homebrew-on-Linux).

## How is this maintained?

Formulae in `Formula/` are auto-generated and pushed here by
[cargo-dist](https://axodotdev.github.io/cargo-dist/) on every tagged
release of `BO4E-CLI` — do not edit them by hand.
